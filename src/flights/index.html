Search Guide:

I have a 100 query per month limit, so flights are not queried on page load. Also, flights are limited to the current day. (No historical data.)
But you can search by airline name, flight number, flight status, or IATA code for airline, flight, departure, and arrival. Browse all flights shows 100 current flights. Use that to get an idea of what the search terms are.

Accepted Flight statuses

  • scheduled
  • active
  • landed
  • cancelled
  • incident
  • diverted

Only these 6 are accepted.
